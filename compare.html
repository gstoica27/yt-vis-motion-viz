Cross-dataset stats — DAVIS · YT-VIS · MammalNet

Three pooled distributions over 3D point tracks for the in-the-wild datasets we host. Sample size = 20,000 values per (dataset, metric); frame-length panel uses the full clip count. Linear x-axis with adjustable zoom; toggle datasets via the legend.
← YT-VIS clips MammalNet clips YT-VIS stats MammalNet stats

1. Raw position magnitude ‖pt‖₂

Distance from camera/origin for each visible 3D point at each frame. Reflects scene-scale; mono-depth means scale is not metric.

2. Per-frame motion delta ‖pt − pt−1‖₂

Frame-to-frame point movement. This is the "raw" signal that the per-frame trim + threshold filter operates on.

3. Frame length per clip

Number of frames in each clip's track tensor. Tells you how many frames you can roll out from each clip.
